Read it as written.

.md 파일을 열거나 붙여넣으면 GFM 그대로 읽힙니다. 목차로 넘나들고, 코드는 한 번에 복사하고, 링크 하나로 통째로 공유할 수 있습니다.

  • 파일 · 폴더 열기 · 드래그&드롭
  • GFM · 문법 하이라이팅
  • 목차 · 코드 복사
  • 인쇄/PDF · .md 내려받기
  • 원본 링크 · 본문 링크
  • ZIP · posts/assets
URL · CORS

다른 사이트의 파일은 그 사이트가 CORS를 허용해야 열립니다. GitHub 원문(raw.githubusercontent.com)은 허용되지만, 일반 블로그·드라이브 링크는 막히는 경우가 많습니다. 그때는 파일을 내려받아 열거나 본문을 붙여넣으면 됩니다.

FOLDER · RELATIVE IMAGES

폴더 열기로 상위 폴더(예: 프로젝트 루트)를 한 번에 열면 posts/*.md와 assets/, images/ 이미지가 함께 들어옵니다. 그러면 본문의 ../assets/foo.png 같은 상대 경로가 문서 위치를 기준으로 풀려 그대로 보입니다. 폴더를 끌어다 놓아도 같은 방식으로 읽으며, 폴더에 문서가 여러 개면 가장 위에 있는 문서를 엽니다. 문서만 열어 이미지가 비어 있으면 본문 위에 안내가 뜨고, 거기서 폴더 열기나 이미지 추가로 바로 채울 수 있습니다.

ZIP · POSTS/ASSETS

ZIP 저장은 본문을 posts/{slug}-{해시}.md로, 이미지는 assets/{해시}.png처럼 내용 해시를 이름으로 삼아 담습니다. 같은 이미지는 한 번만 저장되고, 본문 경로도 /assets/…로 함께 바뀝니다. 이미지는 붙여넣은 본문·로컬 파일·URL 어디서 왔든 모읍니다.

SHARE · ?url= / #md=

원본 링크(?url=)는 URL로 연 문서에만 붙습니다. 링크를 열 때마다 그 주소의 원문을 다시 가져오므로, 원본이 바뀌면 링크를 연 내용도 바뀝니다. 본문을 링크에 담기(#md=)는 지금 보고 있는 본문을 압축해 링크 안에 담으므로, 나중에 원본이 바뀌어도 링크를 만든 시점의 내용이 그대로 열립니다. 파일로 열었거나 붙여넣은 문서는 기본 동작이 .md 파일로 내려받기입니다.
